## parts-log-service

Universal parts activity log with a deterministic (non-AI) error catcher and
an autonomous AI remediation pipeline that fixes and deploys straight to
`prod` when a captured error's fix passes tests. See
[`parts-log-service/README.md`](parts-log-service/README.md) for the full
design, API, and configuration.
